# Anti-defense

Project-level guidance for writing simpler, contract-driven code and prose.

- `AGENTS.md` — persistent instructions for Codex and other coding agents.
- `WRITING.md` — principles for concise, non-defensive technical writing.

The rules favor validation at external boundaries, trust in established internal contracts, explicit failures for broken invariants, and focused changes. They are intended for gradual adoption in existing repositories rather than repository-wide rewrites.
